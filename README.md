# Writesea Odyssey Design System

Writesea Odyssey is a React component library built from the Writesea Odyssey Figma design system. It ships accessible, production-ready components built with React 19, Tailwind CSS, and React Aria — with WCAG 2.2 AA accessibility built in.

Built with React 19.2, Tailwind CSS v4.3, TypeScript 5.9, and React Aria, Writesea Odyssey components deliver modern performance, type safety, and maintainability.

## Documentation

Component usage patterns, props, and examples are documented inline via Storybook. Run `pnpm run storybook` to browse the full component catalogue locally.

## Installation

```bash
pnpm install
pnpm run storybook
```

See [CONTRIBUTING.md](./CONTRIBUTING.md) for the full development workflow.

## Icons

Components use [`@untitledui/icons`](https://www.npmjs.com/package/@untitledui/icons), an open-source icon package, as their default icon set.
