title: Bar chart

## Overview

Use `BarChart` for **magnitude by category**. Bars never exceed 24px (the rest of the band is air), are rounded at the data end and square at the baseline, and touching fills are separated by a 2px surface gap rather than a stroke. Horizontal orientation is the right choice for ranked, nominal categories with long labels.

<ComponentPreview demo="application/charts/bar-chart" export="BarChartGrouped" />

## Installation

```ts
import { BarChart } from "@/components/application/charts/bar-chart";
```

## Usage

```tsx
<BarChart
    label="Applications and interviews by month"
    data={rows}
    xKey="month"
    series={[
        { key: "applications", name: "Applications" },
        { key: "interviews", name: "Interviews" },
    ]}
/>

// Ranked categories: one hue, values at the tip
<BarChart label="Skills in matched job posts" data={skills} xKey="skill" series={[{ key: "posts" }]} orientation="horizontal" showValues />

// Signed values around a zero baseline
<BarChart label="Score vs benchmark" data={scores} xKey="skill" series={[{ key: "delta" }]} mode="diverging" orientation="horizontal" showValues />
```

### Basic

## Accessibility

Every Odyssey chart uses the same keyboard and screen-reader model, provided by the shared `Chart` root and the `useChartFocus` hook:

| Key                               | Action                                                                                                          |
| :-------------------------------- | :-------------------------------------------------------------------------------------------------------------- |
| <kbd>Tab</kbd>                    | Moves focus into the chart (one tab stop: the last visited mark, or the first).                                 |
| <kbd>←</kbd> <kbd>→</kbd>         | Move to the previous / next data point (or bar).                                                                |
| <kbd>↑</kbd> <kbd>↓</kbd>         | Move between series at the same category. With a single series all four arrows walk the bars.                   |
| <kbd>Home</kbd> <kbd>End</kbd>    | Jump to the first / last point. <kbd>Ctrl</kbd>+<kbd>Home</kbd>/<kbd>End</kbd> jump to the first / last series. |
| <kbd>Enter</kbd> <kbd>Space</kbd> | Activate the mark (`onBarSelect`).                                                                              |
| <kbd>Esc</kbd>                    | Close the tooltip and drop focus.                                                                               |

- The root is a `figure` named by `label` and described by `description` (a sentence is generated from the data when you omit it).
- Each mark is a focusable `role="img"` element whose accessible name reads like “May, Applications, 78”. Focusing it shows the same tooltip pointer users get, plus a 2px focus ring drawn in the design system's focus-ring color.
- Every value is mirrored in a data table rendered for assistive technology. Pass `showTable` to render it visibly.
- Motion respects `prefers-reduced-motion`: the final frame renders immediately.
- An empty `data` array renders a labelled empty state, never a blank plot.
