## Overview

Use `StatTile` when **the story is a single number**. The most common way a chart misses its point is eight series where one figure would do. A tile carries a label, a value in proportional figures, a signed delta colored by whether the direction is good, and an optional sparkline. Group tiles with `StatTileGroup`.

<ComponentPreview demo="application/charts/stat-tile" export="StatTileGroupDemo" />

## Installation

```ts
import { StatTile } from "@/components/application/charts/stat-tile";
```

## Usage

```tsx
<StatTileGroup>
    <StatTile label="Profile views" value={1284} delta={{ value: "12.4%", direction: "up", caption: "vs last month" }} trend={views} />
    <StatTile label="Applications sent" value={286} delta={{ value: "8.1%", direction: "up", caption: "vs last month" }} trend={applications} />
    <StatTile label="Response rate" value="31%" delta={{ value: "2.3 pts", direction: "down", caption: "vs last month" }} trend={responses} />
</StatTileGroup>
```

## Accessibility

A stat tile is a `group` named by its label; the value and delta are plain text, so they are read in order. The delta always carries an arrow icon and a sign in addition to color. Numeric values count up on entry unless the reader prefers reduced motion.
