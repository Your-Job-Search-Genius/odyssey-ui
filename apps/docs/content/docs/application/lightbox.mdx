## Usage

Full-bleed image viewer over a near-opaque frosted backdrop (a ModalOverlay with backdrop="lightbox"): the current photo on a glass card with its own colour glow, actions below it, previous/next buttons at the screen edges and a peek of the next photo. Lightbox props: images (\{ src, alt \}[], required), index + onIndexChange (controlled) or defaultIndex (default 0), header (ReactNode or (index) => ReactNode, caption above the card), actions (ReactNode or (index) => ReactNode, use LightboxAction), aria-label (default "Image viewer"), plus ModalOverlay props (isOpen, onOpenChange, isDismissable...). Open it inside a DialogTrigger or with isOpen/onOpenChange. LightboxAction props: label (visible text and accessible name), icon (required), shape circle (56px round, default) | square (55px tile), isSelected (sets aria-pressed and fills the icon), plus Button press props.

**Controlled with favourite and download**

```tsx
<Lightbox
    isOpen={isOpen}
    onOpenChange={setIsOpen}
    images={images}
    actions={(index) => (
        <>
            <LightboxAction label="Add to Favorite" icon={FavouriteIcon} isSelected={favourites.has(index)} onPress={() => toggle(index)} />
            <LightboxAction label="Download" icon={ImageDownloadIcon} shape="square" />
        </>
    )}
/>
```

## Accessibility

A modal dialog named by aria-label: focus is trapped and returns to the trigger, Escape closes, Left/Right arrows step through images. A polite live region announces "Image n of total"; each photo's alt text says what it is. Close, Previous image and Next image are labelled icon buttons (disabled at the ends); the glow and peek images are aria-hidden. LightboxAction uses aria-pressed when isSelected is set.
