## Usage

```tsx
<Alert color="warning" title="Branching needs two paths" description="Connect a Yes and a No step before publishing." />;

// Transient notifications: mount <Toaster /> once near the app root, then call toast() anywhere.
toast.success("Template saved");
toast.error("Refresh failed", { description: error.message, duration: Infinity });
```

`description` can hold block content (lists, a `CodeBlock`). In dark mode alerts sit on the subtle `bg-*-primary` surfaces so the description and icon stay readable.

## Accessibility

- `error` and `warning` use `role="alert"` (assertive); `info` and `success` use `role="status"` (polite).
- A dismissible `Alert` focuses its close button when it mounts -- right for alerts that appear in response to an action; pass `autoFocus={false}` for alerts present on page load.
- Toasts don't move focus by default (so a routine "Saved" never interrupts the task). Pass `{ autoFocus: true }` when the toast holds an action the user should take now, and `{ duration: Infinity }` for errors that must be read. Hovering or keyboard-focusing a toast pauses its timer.
