
## Usage

```tsx
<TagGroup label="Selected schools" onRemove={(keys) => setSelected((prev) => prev.filter((school) => !keys.has(school.id)))}>
    <TagList items={selected}>{(school) => <Tag id={school.id}>{school.name}</Tag>}</TagList>
</TagGroup>
```

<Callout type="warn">
    `TagList` caches rendered items, so a callback created per tag (e.g. `onClose={() => remove(tag.id)}` that closes over the list) can run with stale state --
    removing one chip can remove them all. Handle removal once on `TagGroup` with `onRemove`, or read the latest list from a ref.
</Callout>

## Accessibility

- Arrow keys move between tags; <kbd>Backspace</kbd> or <kbd>Delete</kbd> removes the focused tag when the group is removable.
- Give the group a `label`. Remove buttons are always visible and reachable, never hover-only.
