## Overview

`CodeBlock` shows text verbatim in the monospace font: API payloads, audit-log diffs, sync logs, generated keys. It is the approved replacement for a raw `<pre>` / `<code>`, which `validate_jsx` rejects. There is no syntax highlighting; `language` is only a caption.

<ComponentPreview demo="base/code-block/code-block" export="DefaultDemo" />

## Installation

```ts
import { CodeBlock } from "@/components/base/code-block/code-block";
```

## Usage

```tsx
<CodeBlock language="JSON" code={JSON.stringify(payload, null, 2)} />

// Feedback that matters: show a toast on copy.
<CodeBlock code={apiKey} onCopy={({ success }) => (success ? toast.success("Copied") : toast.error("Copy failed"))} />
```

## Accessibility

- The copy button has an accessible name, and the result ("Copied to clipboard") is announced in a polite live region.
- When the content can scroll (long unwrapped lines, or `maxHeight`), the block is a focusable, labelled region so keyboard users can scroll it. The label defaults to `language`, then "Code"; override it with `aria-label`.
