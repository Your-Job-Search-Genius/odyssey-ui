## Accessibility

- Follows the ARIA combobox pattern: type to filter, arrow keys move through options, <kbd>Enter</kbd> selects, <kbd>Esc</kbd> closes.
- The menu opens on focus, so don't `autoFocus` a combobox (for example as a dialog's first field) -- its menu would cover the form.
- The ⌘K hint (`shortcut`) is decorative and off by default; only enable it when your app actually focuses the combobox on ⌘K.
