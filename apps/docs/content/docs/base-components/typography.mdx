## Usage

Reach for `Heading` whenever text is structurally a heading -- it's the only component in this
family that affects the document outline. Everything else is presentational:

- `Text`, `Strong`, and `Em` style a run of inline text without changing its block layout.
- `Paragraph`, `Body1`, and `Body2` are block body copy at decreasing size/emphasis --
  `Paragraph` for primary reading content, `Body1`/`Body2` for secondary or supporting copy.
- `Caption` is the smallest supporting text, for captions, timestamps, and helper labels.
- `Title`, `Subtitle`, and `Subtitle2` are large, heading-_styled_ text for places like empty
  states or page headers where you want heading-sized type without claiming a heading level.

```tsx
import { Body1 } from "@/components/base/typography/body-1";
import { Heading } from "@/components/base/typography/heading";

<Heading level={1}>Dashboard</Heading>
<Body1>An overview of your team's activity this week.</Body1>
```

Every component accepts a `color` prop drawn from the library's semantic text-color tokens (see
[Theming](/docs/getting-started/theming)) and forwards `className`/native props for one-off
overrides.

## Accessibility

- `Heading`'s `level` and `size` are intentionally decoupled: `level` sets the rendered tag
  (`h1`-`h6`) and drives the document outline, while `size` only changes the visual scale.
  Choose `level` based on document structure first, and use `size` if you need it to look larger
  or smaller than that level implies -- never skip heading levels purely for a visual effect.
- `Title`, `Subtitle`, and `Subtitle2` render as `<p>` on purpose. They do not participate in the
  heading outline, so don't use them as a substitute for `Heading` when text is structurally a
  heading (e.g. a section's leading title) -- screen reader users navigating by heading won't see
  them.
- `Strong` and `Em` carry meaning to assistive technology (importance and stress emphasis,
  respectively), not just a visual style. Use them for text that's genuinely emphasized, and use
  `Text` with a `className` override for purely decorative bold/italic styling.
