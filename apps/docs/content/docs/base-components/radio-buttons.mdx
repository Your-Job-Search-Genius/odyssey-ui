## Accessibility

- `RadioGroup` renders a `radiogroup`; each `RadioButton` is a native radio. Give the group an `aria-label`, or `aria-labelledby` pointing at a visible heading.
- Tab moves into the group (to the selected radio), arrow keys move and select. With `orientation="horizontal"`, Left/Right follow the reading direction.
