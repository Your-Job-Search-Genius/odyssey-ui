## Accessibility

- Single selection (the default) renders a `radiogroup` of `radio`s -- query items with `getByRole("radio")` in tests. `selectionMode="multiple"` renders toggle buttons with `aria-pressed`.
- Give the group an `aria-label`; icon-only items need their own `aria-label`.
- The selected item gets a distinct surface and, for text items, a leading check -- selection is never shown by color alone. Turn the check off with `showSelectedIndicator={false}` only when selection is conveyed another way.
