## Overview

**Writesea Odyssey** is the component library behind Your Job Search Genius. It's built on
[React Aria Components](https://react-spectrum.adobe.com/react-aria/) for accessibility and
behavior, styled with [Tailwind CSS v4](https://tailwindcss.com), and written entirely in
TypeScript.

This site documents every component in the library with:

- A live, interactive **preview** of each example, rendered from the real component -- not a
  screenshot or a copy.
- The exact **source code** for every example, always in sync with the actual `*.demo.tsx` file
  it's read from.
- A **playground** for key components, so you can toggle real props and watch the component
  re-render live.
- A full **props table** for every component, generated from its actual TypeScript types.

## How this site is organized

- **Base Components** -- buttons, inputs, selects, badges, and other foundational controls.
- **Application** -- higher-order patterns like modals, tables, date pickers, and charts.
- **Foundations** -- icons, featured icons, logos, and other visual primitives.
- **Shared Assets** -- illustrations, credit cards, background patterns, and similar assets.
- **MCP** (separate sidebar tab) -- connect AI assistants (Claude, ChatGPT, Cursor, ...) to
  this design system through the [MCP server](/docs/mcp).
